Note-Taking App
Project Description
A desktop note-taking application developed using Python and Tkinter. The application allows users to create, organize, edit, and manage their notes through a simple graphical user interface.

Technologies Used
* Python
* Tkinter (GUI)
* JSON (Data Storage)

Features
* User login with password protection
* Create and save notes
* Edit and delete existing notes
* Organize notes into Personal and Work categories
* Search for saved notes
* Store notes using JSON
* User-friendly graphical interface

How to Run
1. Install Python on your computer.
2. Download the project files.
3. Open the project in Visual Studio Code.
4. Run ReemNoteTakingApp.py to launch the application.
